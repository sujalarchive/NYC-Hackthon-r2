# 📖 About

Todo App is a lightweight task management application that helps users stay organized by creating, tracking, and managing daily tasks.

Built using **HTML, CSS, and JavaScript**, the project focuses on simplicity, responsiveness, and an intuitive user experience.

---

# ✨ Features

- ✅ Add new tasks
- 📝 Edit existing tasks
- ❌ Delete tasks
- ✔️ Mark tasks as completed
- 📱 Fully Responsive Design
- ⚡ Fast & Lightweight
- 🎨 Clean and Modern UI

---

# 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

1. Clone the repository

3. Run `index.html` in your browser.
